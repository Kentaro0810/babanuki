# ROYAL MAID 4人ババ抜き

あなた1人とBOT3人で遊ぶ、カジノ風のババ抜きWebゲームです。完全静的でGitHub Pagesにそのまま公開できます。

## 実装内容
- ジョーカー1枚を含む53枚
- 配札後とドロー後のペア自動処理
- 先行を「あなた・各BOT・ランダム」から選択
- 時計回り・反時計回り・ゲームごとランダム
- 1・2・3・5・7本先取
- 勝者決定後もババが決まるまで続行
- 個別勝利数、順位、ゲーム履歴
- iPad・スマートフォン対応

## GitHub Pages
ZIPを展開し、全ファイルをPublicリポジトリ直下へアップロード。Settings → Pages → Deploy from a branch → main / rootを選択します。
